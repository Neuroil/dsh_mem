## 1. 背景与核心立场

### 1.1 出发点（来自 1.md）

1. **遗忘的本质是语义操作而非时间操作**：多数遗忘是"提取失败"——缺少正确的语义线索，或被语义相近的记忆干扰；大脑甚至主动抑制语义竞争者。遗忘是适应性的认知经济。
2. **巩固（短→长）由语义因素选择**：重要性/奖赏相关性、图式契合度、情绪唤醒、主动提取（测试效应）——几乎全是语义变量。
3. **语义化本身是建设性遗忘**：情景记忆经反复提取与概括后丢失情境细节、保留语义要点（gist）；"记住要点、忘掉细节"是长期知识形成的必经过程。
4. **总哲学**：好记忆系统的核心不是存了多少，而是在正确的语义语境下高效唤醒该唤醒的、优雅抑制不该干扰的。

### 1.2 核心立场（一句话）

> **遗忘与巩固由语义而非时间决定。时间戳只作为元数据保存，永不作为衰减/删除的驱动。**

### 1.3 业界佐证

记忆系统的演化方向恰是从时间驱动转向语义驱动：

- 时间衰减派：Generative Agents（recency = 0.995^h）、MemoryOS（exp(−Δt/μ)）
- 语义失效派：Mem0（矛盾才 DELETE）、Zep / Graphiti（边软失效，双时间戳）

本设计与后者同向，并更进一步：把"语义"拆解为六个可计算量（§3），使"以语义为货币"成为可实现的工程约定。

## 2. 机制总览：五根支柱

| # | 支柱 | 一句话 | 证据强度 | 优先级 |
|---|------|--------|:---:|:---:|
| 一 | 巩固分数 S(m) | 动态分数替代时间衰减；低分沉入低可及性层而非删除 | 工程先例（MemoryOS Heat） | P2 |
| 二 | 检索时语义抑制（弱形式） | 查询内竞争归一化 + MMR 去冗余；抑制只记录、不持久扣分 | 现象 ★ / 机制 △ | P0（随检索链路） |
| 三 | 情景→语义离线转化 | "睡眠"周期：聚类 → gist 抽取 → 挂入语义网络 | 工程 + 认知双强 | **P1（最高收益）** |
| 四 | 语义线索质量决定可提取性 | CSLS 校正的区分度；时间降级为查询时特征 | ★（CSLS/hubness） | P0 |
| 五 | 矛盾检测与软失效 | 被取代的记忆软失效（valid_at/invalid_at），不删除 | 工程强先例（Zep/Mem0） | P0 简化版 / P2 完整版 |

### 2.1 支柱一：巩固分数 S(m)

每条记忆维护一个动态分数，事件驱动更新，替代时间衰减：

```
初始：      S ← imp(m)                        （M5 判分，1–10 标度）
成功使用：  S ← S + α·(1 + cue_quality)       α = 0.5
被抑制：    S ← S − ε                          ε = 0.05（每查询至多计一次）
兜底衰减：  S ← S · e^(−1/τ)（每日）           τ = 180 天 → 半衰期约 125 天
```

- **"成功使用"的定义**：记忆进入最终上下文、且生成的回答被采纳/未被纠正。按成功使用而非被检索增长——测试效应证据强度 ★（Rowland 2014 元分析，g ≈ 0.50），且"被采纳"是比"出现在候选列表"干净得多的信号。可观测信号的落地映射见 §5.0（工具路径 + messageFeedback）。
- **兜底衰减是工程保险而非认知主张**：所有语义指标都是概率性的，慢衰减保证"过时但无矛盾"的垃圾记忆最终有出口；它只影响分层，永不触发删除。
- **分层**（对应 1.md 的"沉入低可及性层"）：

| 层 | 条件 | 行为 |
|---|---|---|
| hot | S ≥ 8 | 常规检索候选 |
| warm | 2 ≤ S < 8 | 常规检索候选 |
| cold | S < 2 | 需更强语义线索才唤醒（CSLS 校正分需再超阈值 +0.1） |

- 二期：间隔效应加权（Cepeda 2006/2008：最优复习间隔 ≈ 保持期 10–20%，且比率随保持期下降）——使用事件的增益 α 乘以 w_space，在最优间隔窗口取峰。

### 2.2 支柱二：检索时语义抑制（仅弱形式）

- **做**：检索链路内部的竞争——CSLS 重排、MMR 去冗余、同线索多候选竞争时落选者记 `suppressed_count`（供 S 消费的小权重信号）。
- **不做**：持久性抑制扣分。提取诱发遗忘（Anderson, Bjork & Bjork 1994）效应本身可靠，但"主动抑制"机制解释有争议（Murayama 2014 元分析：效应在再认测验与独立探测下显著缩水）。不过度投资认知保真度。
- **已知风险**：语义冗余的两条记忆可能在关键细节上不同，MMR 抑制可能压掉正确的那条。缓解：MMR 只在最终 top-5 输出阶段生效；被抑制项保留在日志中可回溯。

### 2.3 支柱三：情景→语义离线转化（"睡眠"周期）

**收益最确定的机制，最高优先级。** 工程证据：A-MEM 消融显示去掉链接+记忆演化后 multi-hop F1 从 45.85 跌至 24.55；Letta sleep-time 同等精度省约 5 倍算力、加大投入再提 13–18% 精度。认知证据：gist 遗忘慢于细节（Sacripante 2022 等）。且摘要+抽象是 LLM 原生能力。

离线周期流程（触发机制见 §5.3：`ctx.schedule` 定时或轮次结束信号）：

```
1. 聚类：red 高的记忆构成连通分量 → 压缩候选簇
2. gist 抽取：LLM 对簇做摘要抽象（例："用户多次提到部署延迟与配置复杂性相关"）
3. QA 闸门（防错误 gist 固化传播）：压缩前从簇生成 QA 对，仅用 gist 作答，
   F1 ≥ 0.8 才通过；不通过 → 保留原簇并标记"不可压缩"
4. M4 路由：con 判定挂入已有语义节点 or 建新节点
5. M6 评估：epi 下降量 = "细节遗忘量"的量化；epi 足够低 → 迁入语义层
6. 原始情景记忆压缩存储，仅保留回溯索引（compressed_into 指向 gist）
7. 刷新 red / con / r_M 统计
```

### 2.4 支柱四：语义线索质量决定可提取性

- 可提取性由 **CSLS 校正的线索区分度**（M2）决定，而非时间距离——落实"十年前语义相关的原则 > 一分钟前的无关闲聊"。
- **补丁（对 1.md 的精确化）**：时间不参与存储层衰减，但**降级为查询时特征**——当查询含时间意图（"昨天定了什么"）时启用 recency 排序特征。完全去时间化会让时间锚定查询失效（Generative Agents 给 recency 1/3 权重的原因）。

### 2.5 支柱五：矛盾检测与软失效（新增支柱）

**1.md 的缺口：只讲"忘掉不重要的"，没讲"已经变成错的了"。** 遗忘的真正对手不是时间，是被取代（supersession）。业界抛弃时间衰减后，填坑的正是这个机制。

- 每条记忆/边维护 `valid_at / invalid_at` 双时间戳（Zep 式）。
- 写入时：对 top 相似且当前有效的记忆做 LLM 判定（Mem0 式 ADD/UPDATE/DELETE/NOOP 的变体）：
  - **矛盾且时间上重叠** → 旧记忆 `invalid_at = now`，`superseded_by = 新记忆`（软失效，不删除）；
  - **补充** → 建立补充链接；
  - **重复** → 合并（NOOP 路径）。
- 软失效记忆默认排除出检索；支持"时间旅行"查询（任意时点重建记忆状态）——P2 完整版。

## 3. 语义量化指标体系（本文档核心）

### 3.0 "语义"的角色分解

| # | 角色 | 指标 | 服务于 |
|---|------|------|--------|
| 1 | 查询↔记忆的相关性 | M1 | 检索 |
| 2 | 线索的区分度 | M2 | 线索质量、抑制 |
| 3 | 记忆↔记忆的冗余/竞争 | M3 | 抑制、压缩触发 |
| 4 | 与知识网络的契合/偏离 | M4 | 巩固路由 |
| 5 | 重要性/情绪权重 | M5 | 巩固优先级 |
| 6 | 情景度（情境绑定深浅） | M6 | 分层、语义化进度 |

### 3.1 M1 相关性 `sim`：两级检索

```
L0 召回：  bi-encoder 余弦，ANN 取 top-100        （嵌入：bge-m3，1024d，多语言）
L1 精排：  cross-encoder 打分 ∈ [0,1]，top-20      （bge-reranker-v2-m3）
查询侧：   q' = query ⊕ 最近 N=3 轮摘要            （同时实现"提取时的语义连贯性"）
```

- 依据：DPR（Karpukhin 2020）+ cross-encoder 精排（Nogueira & Cho 2019）是业界强共识；cross-encoder 逐对打分天然规避 hubness。
- 约束：精排分只做**同查询内排序**，不跨查询比较（无标定）。
- 嵌入与重排模型是**插件自有依赖**：dsh 无内置嵌入/reranker 服务（全量 seam 目录已核实），端点、模型与维度经 Config 配置（§5.0）；bge-m3 / bge-reranker-v2-m3 仅为默认值。

### 3.2 M2 线索区分度 `cue`：CSLS 校正 ★本方案关键创新点

```
cue(q, m) = 2·cos(q, m) − r(q) − r(m)
r(m)  = m 与记忆库中 K=10 近邻的平均余弦   （预计算，写入时与夜间刷新）
r(q)  = q 与当前候选池的平均余弦           （检索时顺带算出，零额外成本）
接入位置：L0（top-100）与 L1 之间——余弦召回 → CSLS 重排取 top-20 → 精排
```

- **语义**：泛化记忆（"和什么都沾边"，r(m) 大）被压分；对*该查询*独特匹配的记忆被抬升。即 TF-IDF 思想的嵌入版。
- 依据：CSLS（Dinu 2015；Conneau 2018）是 hubness 校正标准做法；hubness 现象本身 ★（Radovanović 2010, JMLR）。跨语言检索中验证充分，迁移到记忆库是合理假设。
- hub 必须在进精排前被压下，否则独特匹配进不了候选池。
- `cue` 值同时记录为该记忆的"线索质量"证据，供巩固分数消费。

### 3.3 M3 冗余/竞争度 `red` 与检索抑制

```
red(m) = m 与记忆库 top-5 近邻的平均余弦        （夜间批量刷新）
MMR：   argmax_m [ λ·R(m) − (1−λ)·max_{s∈已选集} cos(m, s) ]    λ = 0.6
压缩触发：簇内平均 pairwise 余弦 > 0.75 且簇大小 ≥ 3 → 离线压缩候选
```

- 三处消费：(a) 最终输出 MMR 去冗余；(b) 离线压缩触发（支柱三）；(c) fan 效应的工程对应——共享线索的记忆越多竞争越强（Anderson 1974 现象 ★），落选计数进 S。

### 3.4 M4 图式契合度 `con`（二期备选：惊奇度 `sur`）

```
con(m) = z-score( max_{node∈语义网络} cos(e(m), e(node)) )
         （相对近期记忆总体的滚动分布做 z 标准化，窗口 = 最近 1000 条）
```

路由规则（默认值，待标定）：

| 条件 | 动作 | 依据 |
|---|---|---|
| con > +0.5σ 且信息兼容（LLM 复核） | 挂入已有语义节点并强化 | Tse 2007：图式一致信息快速巩固 |
| con < −1σ 且 imp ≥ 7 | 建新语义节点 | von Restorff：离群但显著也该记 |
| 其余 | 留情景层，等下个巩固周期 | — |

- 裸余弦数值不稳定，z 化后阈值才有意义。
- 二期 `sur(m) = −log p(m | 最近节点摘要)`（token 级 NLL）：surprisal 与加工难度有强实证关联（Hale 2001; Levy 2008），但 NLL 跨模型不可标定，且 `ctx.llm` 公开流协议未含 logprobs，启用时需自备推理依赖。**默认关闭，仅作序数信号**。

### 3.5 M5 重要性 `imp`：结构化 rubric 判分

```json
{"importance": 1-10, "valence": [-1,1], "arousal": [0,1],
 "reasons": ["task_impact"|"user_identity"|"decision"|"emotion"|"reversible"]}
```

- 判分维度对齐 1.md 的巩固因素：任务影响、用户身份/偏好相关、决策相关性、情绪效价/唤醒、不可逆性。
- temp = 0，带锚定示例（Generative Agents 锚定法：刷牙 = 2、约 crush 出去 = 8）；重判时取 EMA。
- 成本：写入路径每条记忆一次 LLM 判分调用（经 `ctx.llm` 的提供方无关流服务，判分模型经 Config 选择，见 §5.0）；只在层级跃迁时重判。
- `arousal` 作为巩固增益的乘法门；`valence` 存档供二期情绪一致性检索。
- 效度门槛：与人工标注 Spearman ρ > 0.7。

### 3.6 M6 情景度 `epi`：语义化进度的度量尺

```
epi(m) = σ( a·z(实体密度) + b·z(时间表达密度) − c·G(m) )     a = b = c = 1
G(m)   = m 对预置多样化探针集 P（|P| = 20）的平均相关度      （仅离线、簇代表上算）
```

- 实体密度、时间表达密度：NER 统计，写入时算（工程特征，可解释；无强文献背书，属已知妥协）。
- `G(m)` 的直觉：语义记忆对多样问题都有中等相关（gist 通用）；情景记忆只对少数特定查询尖峰相关（高均值低方差 vs 低均值高方差）。
- 特征先 z 标准化再合成（否则 logit 尺度无意义）。
- **用途**：epi 高 → 情景层；摘要抽象后 epi 下降 → 迁语义层。epi 的下降量 = "细节遗忘量"的量化，即 1.md"语义化伴随细节遗忘"的可测表述。

## 4. 记忆数据模型

### 4.1 MemoryRecord（情景层与语义层通用）

```
{
  id, text, embedding,
  imp, valence, arousal,          // M5
  epi, red, tier,                 // M6 / M3 / 分层
  con_route,                      // attached_node_ids | new_node | pending
  links[],                        // 语义图边（关系类型待二期细化）
  S,                              // 巩固分数
  counters: { used_count, suppressed_count, last_used_at, last_cue_quality },
  time_meta: { created_at, valid_at, invalid_at },   // 全部为元数据，永不驱动衰减
  flags: { superseded_by, compressed_into, qa_passed }
}
```

### 4.2 SemanticNode（语义层，图结构）

```
{ id, gist, embedding, epi(低), links[], member_refs(原始情景索引), 
  time_meta: { valid_at, invalid_at }, S }
```

- 语义层从第一天起就是**图**而非扁平集合——为二期 PPR 联想检索（HippoRAG 式）预留结构，multi-hop 收益已被 A-MEM/HippoRAG 消融证实。
- 持久化落地：全部记录经 `ctx.storage` / `ctx.storageDomain` 存取（dsh 非会话数据的规范存储 seam，后端可选 storage-json / storage-sqlite），**不自建数据库或裸文件**；情景记忆的"压缩存储"同在此存储内（§5.0）。

## 5. 运行时流程

### 5.0 宿主框架对接规范（dsh / Cordis）

本插件宿主为 **DeepSeek Harness（dsh）**："一切皆插件"，底层为 vendored 的 Cordis 插件框架。本节规定落地时必须遵守的框架契约；API 名称以 `docs/ref/` 官方文档为准。

**记忆触达模型的规范通道**（dsh 官方"功能→机制映射"明确：记忆 = section 提供方 + 工具）：

1. **section 提供方**：`ctx.systemPrompt.section()` 注册（支持排序与作用域），随每步 `system-prompt/assemble` 组装注入当前相关记忆——§5.2 检索链路的自动通道；
2. **记忆工具**：`ctx.tools.register(defineTool(...))` 提供 `memory_search` 等按需检索工具——模型主动召回通道；
3. **按需注入**：`agent.inject({ content, source })` 用于事件驱动的补充上下文（落入下一次获准的请求，**不是唤醒**；source kind 需在 MessageSourceMap 中声明）。

禁止绕过上述通道直接改写消息——dsh 的铁律是**"模型可见即已记录"**：一切模型可见输入必须可从会话日志重建。

**触发与信号机制**：

- 写入观察：监听 `session/event`（持久事件信封 `{seq, time, type, data}`），过滤 `user/message`、`assistant/message`、`turn/end` 等持久类型；`agent/*` 是实时事件、不落盘，不用于写入。
- 巩固周期：`ctx.schedule` 定时（到期以 `followup(…, {source: {kind: 'schedule'}})` 投递回原会话）；或经工具 `run_in_background` + `ctx.jobs.start()` 登记后台任务（owner 为 agent，含会话围栏与 owner cleanup）。触发信号可取 `turn/end` / `workspace/session-stop`。
- 用户反馈：`ctx.messageFeedback`（`feedback/committed` 事件）提供逐 assistant 消息的用户评价，是"成功使用"中"被采纳"信号的规范来源（反馈不进入模型历史）。

**服务使用**：

- 内部 LLM 调用（M5 判分 / 矛盾判定 / gist 抽取）一律走 `ctx.llm` 的提供方无关流服务（`compaction-basic` 是内部消费方先例），模型经 Config 选择；
- 持久化走 `ctx.storage` / `ctx.storageDomain`（§4），不自建数据库或裸文件；
- 嵌入与重排是插件自有依赖（dsh 无对应 seam），端点与模型经 Config 配置；将来确需可替换时再按三角色（Definition / Provider / Consumer）拆 seam，**不要预防性拆分**。

**插件契约要点**（细节见 `docs/ref/docs`）：

- 函数形态必须具名导出 `name` / `inject` / `Config` / `apply`（不能用 default export，会丢 inject 元数据）；一切注册皆 effect（插件卸载自动逆序清理，手动资源放 `ctx.effect()` 返回 disposer）；
- 本文档所有超参与默认值（K、λ、阈值、τ、模型名等）一律进 Schemastery `Config` schema：默认值写在 schema、**无硬编码可调参数**、非法配置响亮报错、配置变更经 HMR 生效；
- 工具 `execute` 返回**单个规范 JSON 值**（`output.schema` 显式声明 `additionalProperties`，`render` 为纯函数，全程遵守 `exec.signal`；领域性不良结果写入规范值而非抛异常，基础设施故障才抛异常）；
- waterfall 监听器必须调 `next()`（不调即拦截）；仅观察不可变最终结果用 `tools/result`；
- 与 `ctx.compaction`（dsh 自带的**会话内**上下文压缩，`compaction-basic` 在 `agent/pre-step` 串行处理压力）是互补关系：compaction 管单会话上下文裁剪，本插件管跨会话长期记忆，不得混淆或试图替代。

> **实现演进注（2026-10-24，M1/M2/M3，不改本设计定稿）**：实现层在本文基础上追加了两条部署形态约束，权威记录见 `docs/architecture/插件工作原理全景图.md`（§4.7、§5.1）——
> ① **记忆按工作区隔离**：存储 scope = 会话创建目录（`session.header.cwd`）的哈希，一区一 KV unit（`<unit>_ws_<hash>`，无 cwd 回退 `unit` 本名）；写入/检索/巩固/计分全套按作用域独立。本文 §4/§5 所述单库语义在"单个作用域内"完全不变。
> ② **写入观察的"人类输入"判定可配置**：`intake.session.acceptSourceKinds`（默认 `['user']`）+ form 守卫（带 `form` 的插件上下文恒不算对话）；入口总开关 `intake.session.enabled`。
> ③ 存储后端生产推荐 sqlite（`dsh-storage-sqlite`，版本与宿主精确对齐），json 保留为回退。

### 5.1 写入路径（每条候选记忆，O(1) 次模型调用）

触发：监听 `session/event`，在 `turn/end` 后对本轮新增的 `user/message` / `assistant/message` 批量抽取候选记忆（参照 Mem0 的 m=10 消息窗口），再对每条候选执行：

```
1. embedding（bge-m3）
2. M5 rubric 判分（1 次 ctx.llm 调用）
3. ANN 查询：更新 r_M 邻域、red
4. epi 词法部分（NER，本地）
5. 矛盾检测（简化版）：对 top 相似且有效记忆 LLM 判定 → 矛盾则软失效
6. con 路由（尝试挂节点，LLM 兼容性复核）
7. S 初始化为 imp
```

### 5.2 检索路径

```
q' = query ⊕ ctx 摘要
→ ANN 余弦召回 top-100（仅有效记忆；cold 层需更高 cue 阈值）
→ CSLS 重排 → top-20
→ cross-encoder 精排 → top-8
→ MMR（λ=0.6）→ top-5 输出
→ 落选候选记 suppressed_count；被采纳记忆记使用事件（进 S）
```

输出通道（§5.0）：自动注入走 **section 提供方**（随每步 `system-prompt/assemble` 执行本链路并注入 top 记忆）；按需召回走 **`memory_search` 工具**（`defineTool`，返回单个规范 JSON 值）。使用信号的观测源：`memory_search` 的 `tool/call` + `tool/result` 会话事件（检索性使用）；"被采纳"取 `ctx.messageFeedback`（`feedback/committed`）。

### 5.3 离线巩固周期（"睡眠"）

触发机制（§5.0）：`ctx.schedule` 定时（到期经 `followup` 投递回原会话）或 `turn/end` / `workspace/session-stop` 信号；长任务经 `run_in_background` + `ctx.jobs.start()` 登记。流程见 §2.3；外加 Generative Agents 式反思（累计 imp > 150 触发高阶抽象）作为二期可选项。

### 5.4 成本预算

| 时机 | 计算项 | 成本 |
|---|---|---|
| 写入 | embedding + imp 判分 + r_M/red + epi 词法 + con + 矛盾判定 | 1 次嵌入 + 2 次 ctx.llm 调用 + 2 次 ANN |
| 检索 | 召回 100 → CSLS 20 → 精排 → MMR 5 | 1 次 ANN + 20 次 cross-encoder（批量） |
| 离线 | 聚类、gist、G 探针、QA 闸门、统计刷新 | 批处理，空闲期 |

## 7. 验证方案

1. **检索质量**：从自有会话日志抽样标注 query-记忆对，测 nDCG@10 / recall@50。消融四档：裸余弦 → +CSLS → +精排 → +MMR。预期 CSLS 档在记忆库变大后拉开差距（hubness 随库增大恶化）。
2. **imp 效度**：判分 vs 人工标注，Spearman ρ > 0.7。
3. **压缩安全**：QAFactEval 式 QA 保留率 ≥ 0.8（QAFactEval, Fabbri 2022；FactCC 作交叉校验亦可）。
4. **端到端**：LoCoMo 式长程会话回放，LLM-as-judge。**关键消融：语义驱动 vs Generative-Agents 式时间衰减 baseline——直接检验本项目核心假设。**
5. **持续监控**：错误 gist 率（QA 闸门拒收率趋势）、冷层误伤率（cold 层 recall）。

## 8. 决策记录：明确弃用的方案

| 方案 | 弃用理由 |
|---|---|
| 嵌入白化（Su 2021） | 增益不稳定，对部分任务有害（Forooghi 2024）；CSLS 已覆盖其收益 |
| NPMI / 词共现一致性 | 面向词袋主题模型，嵌入场景不需要；与人工判断相关性脆弱（Hoyle 2021） |
| REM 式贝叶斯痕迹模型 | 参数繁多、可辨识性弱（Shiffrin & Steyvers 1997 的已知局限） |
| 强形式 RIF（持久抑制扣分） | 机制解释有争议（Murayama 2014）；只做查询内弱形式 |
| 纯 FEP / 自由能叙事 | 不可证伪争议（Bruineberg 2016）；仅保留 surprisal 序数用法且默认关闭 |
| 纯时间衰减 | 与核心立场相反，与业界新方向相悖；仅保留慢兜底用于分层（永不删除） |

## 9. 证据强度与参考文献

### 9.1 强共识（★）

- hubness 干扰 kNN（Radovanović et al. 2010, JMLR）；CSLS 校正（Dinu 2015; Conneau et al. 2018）
- 两级检索（Karpukhin et al. 2020 DPR; Nogueira & Cho 2019）
- SAM 全局匹配：提取强度 = 线索匹配 / 全部竞争者（Raaijmakers & Shiffrin 1981）——竞争性检索的认知根基
- 测试效应（Roediger & Karpicke 2006; Rowland 2014, g ≈ 0.50）；间隔效应及比例（Cepeda 2006/2008）
- fan 效应现象（Anderson 1974; Radvansky & Zacks 1991 修正）
- surprisal 预测加工难度（Hale 2001; Levy 2008）
- gist 遗忘慢于细节（Sacripante 2022; Robin & Moscovitch 2017）

### 9.2 争议/间接证据（△，设计中的对应处理）

- RIF"主动抑制"机制（Anderson, Bjork & Bjork 1994; Murayama 2014）→ 只做弱形式
- 白化增益（Forooghi 2024）→ 弃用
- 图式一致性方向（Tse 2007 支持 vs von Restorff 反例）→ con 只做路由调制，imp 做门
- 语义化神经机制（标准巩固论 vs 多痕迹论）→ 不依赖神经机制主张，只用行为层结论
- FEP（Friston 2010; Bruineberg 2016 批评）→ sur 默认关闭

### 9.3 工程参考系（关键数字）

- Generative Agents（arXiv:2304.03442）：recency 0.995^h；importance LLM 1–10；反思阈值累计 imp > 150；recency 权重 1/3 → 本设计将其降级为查询时特征
- Mem0（arXiv:2504.19413）：ADD/UPDATE/DELETE/NOOP；LoCoMo 66.88；p95 延迟 1.44s（full-context 72.90 @ 17s）→ 支柱五参考
- Letta sleep-time（arXiv:2504.13171）：整块重写 rethink_memory；等精度省 ~5× 算力，+13–18% → 支柱三参考
- HippoRAG 2（arXiv:2502.14802）：PPR damping 0.5，同义词边 cos > 0.8 → P3 图检索参考
- A-MEM（arXiv:2502.12110）：链接+演化消融 F1 45.85 → 24.55 → 支柱三收益证据
- Zep/Graphiti（arXiv:2501.13956）：valid_at/invalid_at 双时间戳软失效 → 支柱五参考
- MemoryOS（arXiv:2506.06326）：Heat 分数与分层调度（τ = 5 升级、最低 Heat 淘汰）→ 支柱一先例
